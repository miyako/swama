Before you begin

Made for Apple Silicon.

Hardware, software and model requirements
You bringWhat to know
An Apple Silicon MacmacOS 15.4 or newer. These native builds do not support Intel Macs, Windows or Linux.
A compatible MLX modelChoose a model that fits your memory and task. Check its license and instructions. Weights are not included in the download.
4D 20+ for integrationInstall the Swama component and its declared dependencies. Direct CLI/HTTP use does not require 4D or Xcode.
Keep local inference local.

The examples bind to 127.0.0.1:8080. Swama's upstream default is 0.0.0.0:28100; do not expose an unauthenticated server to an untrusted network.

From download to conversation

Your first local request.

This path uses the CLI directly, without starting 4D. If the component is already managing a server on port 8080, use that server instead of starting another one.

01

Choose and download a model

Shell / macOS

Replace the folder path with your extracted download. The qwen3 alias downloads a chat model; allow time and disk space for the weights.

{% highlight shell %} cd "/path/to/swama.4dbase/Resources/bin/macOS" shasum -a 256 --check SHA256SUMS ./swama --version ./swama pull qwen3 {% endhighlight %}
02

Start the engine on localhost

Shell / macOS
{% highlight shell %} ./swama serve --host 127.0.0.1 --port 8080 {% endhighlight %}

Leave it running. In another terminal, wait until model discovery returns HTTP 200. This confirms HTTP readiness, not that model inference has already completed.

{% highlight shell %} curl --fail http://127.0.0.1:8080/v1/models {% endhighlight %}
03

Start a conversation

Shell / macOS
{% highlight shell %} curl --fail http://127.0.0.1:8080/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "qwen3", "messages": [{"role": "user", "content": "Hello from my Mac."}], "max_tokens": 128, "stream": false }' {% endhighlight %}

The first inference may take longer while the model loads. For streaming, use curl -N and set "stream": true. Stop a foreground server with Control-C.

Connect with tools you know

A familiar API. A local address.

Point AI Kit's OpenAI client at your running server. Use a model identifier returned by /v1/models; the 4D guide's custom model is not the CLI's qwen3 alias.

{% highlight 4d %} var $AIClient : cs.AIKit.OpenAI $AIClient:=cs.AIKit.OpenAI.new() $AIClient.baseURL:="http://127.0.0.1:8080/v1" {% endhighlight %}
Swama endpoint compatibility
CapabilityEndpointWhat to know
Model discovery/v1/modelsSupported
Chat completions/v1/chat/completionsVision and function-tool calling depend on the selected model.
Embeddings/v1/embeddingsA separate embedding model is required.
Responses/v1/responsesPartial OpenAI compatibility; not a full replacement.
Audio/v1/audio/transcriptions, /v1/audio/speechSuitable audio models are required.
Images, moderation, filesGeneration, moderation and uploadsNot provided by this integration.

Tool calls are returned to your client, not executed by the server. Follow the selected model's instructions; no blanket 4-bit-only restriction or manual config.json edit is prescribed.
